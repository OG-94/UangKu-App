# UangKu

A personal investment transaction tracker — replacing a Google Sheets–based
workflow with a purpose-built app.

## What it does

Log investment transactions (buy, sell, dividend/interest/coupon), manage
the accounts they belong to, and review transaction history. Built as a
personal project for single-user, local use.

## Stack

- **Frontend:** plain HTML, CSS, and JavaScript (no framework)
- **Backend:** Python, [FastAPI](https://fastapi.tiangolo.com/)
- **Database:** SQLite

See the [Architecture Decisions](https://fauzi94.atlassian.net/wiki/spaces/UANGKU/pages/1212487/UangKu+-+Architecture+Decisions)
page for the reasoning behind these choices.
